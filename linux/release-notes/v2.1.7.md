## 한국어

Windows LLCV 2.1.5~2.1.7 업데이트를 리눅스판에 반영했습니다.

### CMAA2 → NIS 업스케일링 (F6)

- **설정 → 영상 → 표시 → 업스케일링**에서 **CMAA2 → NIS**를 고르면, SDR 영상을 가로·세로 최대 2배까지 확대할 때 CMAA2로 계단 현상을 먼저 줄이고 NVIDIA Image Scaling(NIS)으로 확대·선명화합니다. 기본은 꺼짐이고, **NIS 선명도** 기본값은 **0.15**입니다.
- **F6**(또는 **Alt → 보기**)으로 선명도를 유지한 채 켜고 끕니다. 켜짐·꺼짐·적용 제외 이유가 알림으로 표시되고, Tab 진단에 현재 상태가 나옵니다.
- 화면 표시에만 적용되며 녹화·스크린샷은 캡처 원본을 유지합니다. HDR·P010·원본 크기·축소·2배 초과 확대는 기존 경로를 사용합니다.
- OpenGL 컴퓨트 셰이더(OpenGL 4.3 수준)가 필요합니다. 지원하지 않는 드라이버와 OpenGL ES에서는 사용할 수 없다고 표시하고 기존 경로를 씁니다.
- Windows판 셰이더를 OpenGL용으로 옮겼습니다. CMAA2는 원본 HLSL과 결과가 같은지 비교했고, NIS SDK에서 왼쪽·위쪽 가장자리가 반대편 가장자리를 읽던 오류는 리눅스판에서 고쳤습니다. NVIDIA VSR은 리눅스에 없습니다.

### 캡처 FPS·색 범위

- **직접 고른 FPS는 그대로만 씁니다.** 장치 목록에 없는 FPS는 "지원 안 함"으로 남고 시작 버튼이 꺼지며, 드라이버가 다른 FPS를 적용하면 시작을 중단합니다. **자동 FPS 선택은 기존대로**입니다. 입력이 요청 FPS보다 계속 높으면 Tab 진단과 로그에 경고합니다.
- **SDR 색 범위**(자동 / Limited / Full)를 **색 공간**(자동 / BT.709 / BT.601)과 나눴고, 재생·스크린샷·녹화에 함께 적용합니다. P010/HDR에는 적용하지 않습니다. 이전 버전의 합쳐진 색 옵션은 자동으로 두 옵션으로 나뉩니다.
- 40fps 캡처와 목록에 없는 30fps 요청을 프레임레이트 옆 **추가 설정**으로 모았습니다.

### 그 밖의 변경

- 업데이트 뒤 첫 실행에는 **다음 실행부터 설정 화면 건너뛰기**가 켜져 있어도 설정 화면을 한 번 보여줍니다. 그 선택은 바꾸지 않으며 다음 실행부터 다시 적용됩니다.
- 녹화 중 남은 저장 공간 확인을 별도 스레드에서 해서 인코딩을 막지 않습니다.
- 단축키에 **CMAA2 → NIS 업스케일링 켜기/끄기**(기본 F6)를 추가했습니다. F6을 이미 다른 동작에 쓰고 있으면 비어 있는 기능 키를 배정합니다.

Windows판의 **캡처 해상도와 동일** 표시 크기 연동은 리눅스판에 해당하지 않습니다. 리눅스판 창 크기는 원래 캡처 해상도를 따릅니다. 기존 설치 경로와 설정은 유지됩니다. 배포 전 테스트 결과와 아직 확인하지 못한 항목은 README의 **테스트 결과 (2.1.7)**에 있습니다.

## English

This release brings the Windows LLCV 2.1.5 to 2.1.7 updates to Linux.

### CMAA2 → NIS upscaling (F6)

- With **Settings → Video → Display → Upscaling** set to **CMAA2 → NIS**, SDR video enlarged by up to 2× per axis first has its jagged edges smoothed by CMAA2, then is enlarged and sharpened by NVIDIA Image Scaling (NIS). It is off by default, and **NIS sharpness** defaults to **0.15**.
- **F6** (or **Alt → View**) turns it on and off without changing the sharpness. A notice shows on, off or why it is bypassed, and the Tab diagnostics show the current state.
- It is display only: recordings and screenshots keep the capture image. HDR, P010, native size, downscaling and enlargement beyond 2× use the normal path.
- It needs OpenGL compute shaders (OpenGL 4.3 level). Drivers without them and OpenGL ES report it as unavailable and keep the normal path.
- The Windows shaders were ported to OpenGL. The CMAA2 port was compared with the original HLSL and gives the same results, and an NIS SDK error that made the left and top edges sample the opposite edge is fixed in the Linux build. NVIDIA VSR is not available on Linux.

### Capture frame rate and color range

- **Explicitly selected frame rates are strict.** A rate the device does not list stays visible as unsupported and Start is disabled, and if the driver applies another rate, startup stops. **Automatic frame-rate selection is unchanged.** The Tab diagnostics and the log warn when the input stays well above the requested rate.
- **SDR color range** (Auto / Limited / Full) is now separate from **Color matrix** (Auto / BT.709 / BT.601) and applies to playback, screenshots and recording. P010/HDR is unaffected. The combined color option of earlier versions is split automatically.
- 40 fps capture and unlisted 30 fps requests are grouped under **More** beside the frame rate.

### Other changes

- After an update, the settings screen is shown once even when **Skip this settings screen on next launch** is on. The preference is unchanged and applies again from the next launch.
- During recording, free-space checks run on a separate thread instead of blocking the encoder.
- New shortcut **Toggle CMAA2 → NIS upscaling** (default F6). If F6 is already used for another action, a free function key is assigned.

The Windows **Same as capture** display-size option does not apply to Linux, where the window size already follows the capture resolution. Installation paths and settings are kept. Pre-release test results and what is not yet checked are in the README under **Tests (2.1.7)**.
