## 한국어

Windows LLCV 2.1.4 수정 사항을 리눅스판에 반영했습니다.

- **F2**나 메뉴의 **설정**은 항상 기본 화면을 엽니다. 영상 모드에서는 **영상**, 오디오 전용 모드에서는 **오디오** 화면입니다. 녹화 옵션은 **녹화** 탭에서 고릅니다. 녹화 중에는 지금처럼 녹화를 멈추고 저장할지 먼저 묻습니다.
- 녹화를 멈출 때 캡처가 넘기던 **마지막 영상·오디오 데이터가 빠질 수 있던 문제**를 고쳤습니다.
- `settings.ini`의 숫자값이 잘못되었으면(뒤에 다른 글자가 붙었거나 범위를 크게 벗어난 값) 앞부분만 읽지 않고 기본값을 씁니다.
- 드리프트 보정 리샘플러가 정규화 합을 프레임마다 한 번만 계산합니다. 출력 소리는 같습니다.

Windows 2.1.4의 큰 오디오 패킷 처리 개선은 리눅스판에 해당하지 않습니다. 리눅스판 녹화는 처음부터 패킷 하나의 크기를 제한하지 않습니다. 진단 로그의 빈 메시지 문제도 Windows에만 있습니다.

기존 설치 경로, 설정, 사용자 지정 단축키는 그대로 유지합니다.

## English

This release brings the Windows LLCV 2.1.4 fixes to Linux.

- **F2** and **Settings** in the menu always open the default page: **Video** in video mode, **Audio** in audio-only mode. Recording options are on the **Recording** tab. During a recording, LLCV still asks first, then stops and saves the recording.
- Fixed possible **loss of the last video and audio packets** when capture delivery overlaps the end of a recording.
- An invalid number in `settings.ini` (trailing characters, or a value far out of range) now falls back to the default instead of using a partial value.
- The drift-correction resampler computes its normalization once per frame. The output sound is unchanged.

The Windows 2.1.4 fix for large audio packets does not apply to Linux: Linux recording never limited the size of a single packet. The empty diagnostic message fix is Windows-only as well.

Installation paths, settings and custom shortcuts are kept.
