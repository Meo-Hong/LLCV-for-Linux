## 한국어

Windows LLCV 2.2.0~2.2.1 업데이트를 리눅스판에 반영했습니다.

### 업스케일링

- **CMAA2 보정**: SDR 업스케일링에서 **높음**(기본)과 **보존형**을 고릅니다. 높음은 경계를 더 부드럽게 다듬고, 보존형은 CMAA2의 extra sharpness 설정으로 글씨와 얇은 선의 원래 모양을 더 유지합니다.
- **HDR10 업스케일링**: HDR 출력에서는 CMAA2 없이 NIS를 PQ 모드로 적용합니다. 그다음 각 채널을 원본 영상 bilinear 샘플의 2 %(최소 10비트 반 단계) 안으로 제한해서, NIS가 가는 윤곽을 어둡게 하거나 깎지 못하게 합니다. CMAA2 보정 설정은 SDR용으로 유지됩니다.
- SDR 화면에서 보는 HDR 입력은 톤매핑한 뒤 SDR 경로(CMAA2 → NIS)를 탑니다. 이전 버전은 이 경우 업스케일링을 건너뛰었습니다.
- Tab 진단과 F6 알림이 HDR에서는 **NIS (HDR10)**, SDR에서는 CMAA2 보정 종류를 보여 줍니다.

### 진단 보고서

- **설정 → 안내 · 로그**의 **보고서 ZIP 만들기**가 최근 로그, `settings.ini`, 버전, 시스템·OpenGL 정보, 장치 목록, 현재 선택과 오류를 ZIP 하나로 모읍니다. `~/.local/state/llcv/reports/`에 저장하고 폴더를 엽니다.
- 홈 폴더, 녹화 폴더, 감지된 장치의 USB 일련번호는 가립니다. 자동으로 전송하지 않으며, 그 밖의 개인 정보가 남아 있을 수 있으니 공유하기 전에 내용을 확인하세요. 원래 로그와 설정은 바뀌지 않습니다.

### 설정 화면

- 스크린샷 설정을 **영상**에서 **앱**으로 옮겼습니다.
- **앱 → 정보**에 현재 버전의 GitHub 릴리스 노트를 브라우저로 여는 **릴리스 노트** 버튼을 넣었습니다.
- 녹화 폴더의 남은 공간을 백그라운드에서 읽어서, 느린 저장 장치 때문에 설정 화면이 멈추지 않습니다.

Windows판과 다른 점:

- Windows판의 다중 입력 WDM 크로스바 연결, Flip VSync 프레임 선택, 콘솔 QuickEdit 처리는 DirectShow·D3D11·Windows 콘솔 전용이라 해당하지 않습니다.
- NIS 선명도는 원래 슬라이더라서 Windows판의 프리셋 목록으로 바꾸지 않았습니다.
- 리눅스판 보고서는 사용자 이름이나 호스트 이름을 일괄 치환하지 않습니다. 짧은 이름이 다른 단어 속에서 바뀌어 로그를 망가뜨릴 수 있기 때문입니다.

기존 설치 경로, 설정, 사용자 지정 단축키는 그대로 유지합니다. CMAA2 보정은 처음에 **높음**이며 이전과 같은 결과입니다.

## English

This release brings the Windows LLCV 2.2.0 and 2.2.1 updates to Linux.

### Upscaling

- **CMAA2 correction**: choose **High** (default) or **Preserve** for SDR upscaling. High smooths more edges. Preserve uses CMAA2's extra-sharpness variant and keeps more of the original text and thin lines.
- **HDR10 upscaling**: with HDR output, NIS runs in its PQ mode without CMAA2. Each output channel is then kept within 2 % (at least half a 10-bit step) of a bilinear sample of the original image, so NIS cannot darken or erode fine contours. The CMAA2 correction setting is kept for SDR.
- HDR input shown on an SDR display now gets the SDR path (CMAA2 → NIS) after tone mapping. Earlier versions bypassed upscaling there.
- The Tab diagnostics and the F6 notice show **NIS (HDR10)** in HDR and the CMAA2 correction in SDR.

### Diagnostic report

- **Settings → Guide & logs → Create report ZIP** collects recent logs, `settings.ini`, versions, system and OpenGL details, the device list, the current selection and errors into one ZIP. It is saved to `~/.local/state/llcv/reports/` and the folder opens.
- The home folder, the recording folder and the USB serial numbers of detected devices are masked. Nothing is uploaded. Other personal text can remain, so read the files before sharing them. The original logs and settings are not changed.

### Settings

- Screenshot settings moved from **Video** to **App**.
- **App → About** has a **Release notes** button that opens the current version's GitHub release notes in the browser.
- The recording folder's free space is read in the background, so a slow drive no longer stalls the settings screen.

Differences from the Windows build:

- The Windows multi-input WDM crossbar routing, Flip VSync frame selection and console QuickEdit handling are specific to DirectShow, D3D11 and the Windows console, so they do not apply.
- NIS sharpness was already a slider on Linux, so it did not change to the Windows preset list.
- The Linux report does not replace user or host names everywhere, because a short name could change unrelated words in the logs.

Installation paths, settings and custom shortcuts are kept. CMAA2 correction starts at **High**, which gives the same result as before.
